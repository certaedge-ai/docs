# 完成第一次调用

本篇使用 Python 3.10 或更新版本，调用 Chat Completions 接口。先准备一把[有效 API Key](/getting-started/api-key)、可用余额，以及支持该接口的<PlatformLink to="models">完整模型 ID</PlatformLink>。

## 1. 准备 Python 环境

若还没有 Python，从 [Python 官网](https://www.python.org/downloads/)安装，再打开新终端。以下命令按你的系统选择一组执行。

macOS / Linux：

```bash
python3 --version
mkdir -p certaedge-test
cd certaedge-test
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade openai
```

Windows PowerShell：

```powershell
py -3 --version
mkdir certaedge-test
cd certaedge-test
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade openai
```

后面的命令直接使用虚拟环境中的 Python，不需要额外执行激活脚本。若目录已存在，直接进入该目录，不重复创建。

## 2. 设置密钥和模型

把 `sk-YOUR_API_KEY` 换成复制的完整密钥，把 `YOUR_MODEL_ID` 换成模型目录中的真实 ID；占位文字不能直接发送。

macOS / Linux：

```bash
export CERTAEDGE_API_KEY='sk-YOUR_API_KEY'
export CERTAEDGE_MODEL='YOUR_MODEL_ID'
```

Windows PowerShell：

```powershell
$env:CERTAEDGE_API_KEY = 'sk-YOUR_API_KEY'
$env:CERTAEDGE_MODEL = 'YOUR_MODEL_ID'
```

这些变量只对当前终端及它启动的程序有效。新开终端后需要重新设置。

## 3. 保存并运行测试程序

在 `certaedge-test` 目录创建 `first_request.py`，用文本编辑器保存以下内容。Windows 注意不要保存成 `first_request.py.txt`。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CERTAEDGE_API_KEY"],
    base_url="https://certaedge.com/v1",
    timeout=60.0,
    max_retries=0,
)

response = client.chat.completions.create(
    model=os.environ["CERTAEDGE_MODEL"],
    messages=[{"role": "user", "content": "请用一句话介绍自己。"}],
    stream=False,
)
print(response.choices[0].message.content)
```

在刚才设置环境变量的同一终端运行。

macOS / Linux：

```bash
.venv/bin/python first_request.py
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe first_request.py
```

## 4. 确认成功

终端输出模型回复，并且<PlatformLink to="logs">使用日志</PlatformLink>中能找到本次请求。核对模型、状态与用量后，再去[配置你的工具](/tools/)。这次模型调用会按所选模型计费。

## 遇到问题

| 提示 | 处理方式 |
| --- | --- |
| 找不到 `python3` 或 `py` | 安装 Python 后打开新终端，再检查版本 |
| `No module named openai` | 确认安装和运行都使用上面同一虚拟环境中的 Python |
| `KeyError: CERTAEDGE_API_KEY` 或 `CERTAEDGE_MODEL` | 在当前终端重新执行第 2 步 |
| 401 / 模型不存在 | 检查密钥和模型 ID，参考[错误排查](/getting-started/troubleshooting) |
| TLS、连接失败或超时 | 先检查服务地址和网络；还没有收到 HTTP 响应时，不是模型名称错误 |

目标模型只支持 Responses、Messages 等协议时，不能直接使用这段 Chat Completions 示例，应选择匹配协议的工具或请求方式。
