# 注册与充值

## 1. 注册并登录

1. 打开 <PlatformLink to="signUp">CertaEdge 注册页面</PlatformLink>。已有账号时直接选择登录。
2. 按页面填写账号信息，完成页面要求的验证并提交注册。若要求邮箱验证码，先获取验证码，再填写收到的内容。
3. 登录后打开<PlatformLink to="keys">API 密钥</PlatformLink>页面，确认能看到密钥列表。

注册方式和验证要求由平台当前设置决定。页面未提供注册入口时，联系 <PlatformLink to="support">CertaEdge 在线客服</PlatformLink>确认账号开通方式。

## 2. 查看价格和可用余额

1. 打开<PlatformLink to="models">模型目录</PlatformLink>，选择准备使用的模型，查看计费单位和价格。
2. 打开<PlatformLink to="wallet">钱包</PlatformLink>，查看当前余额或可用套餐。已有足够可用额度时可直接进入下一步。
3. 需要充值时，在“充值”区域选择金额和页面提供的支付方式，核对实际付款金额，再按提示支付。
4. 付款完成后返回钱包并刷新，确认余额已更新，再发起模型请求。

若使用兑换码，在钱包中的兑换码区域填写并兑换；只有持有有效兑换码时才使用此方式。支付方式、最低金额和兑换入口以页面实际提供的选项为准。

## 3. 确认可以继续

钱包显示可用余额或套餐后，继续[创建 API Key](/getting-started/api-key)。账号余额和密钥额度是两项不同的限制：充值不会自动提高某个密钥的额度。

## 遇到问题

- 收不到验证码：检查邮箱地址和垃圾邮件，等待页面允许重发后再试。
- 支付已完成但余额未更新：先查看充值记录并保留订单号，联系支持核对；不要为了刷新余额重复付款。
- 没有充值或兑换入口：以当前平台开通的方式为准，联系支持确认。
