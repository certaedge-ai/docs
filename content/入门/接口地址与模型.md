# Base URL 与模型选择

CertaEdge 的网页地址与模型 API 路径用途不同。填写前先确认客户端需要的是服务根地址、SDK Base URL，还是完整端点。

## 按协议填写地址

| 场景 | 地址示例 |
| --- | --- |
| OpenAI 兼容 SDK、Dify、n8n 凭证 | `https://certaedge.com/v1` |
| Cherry Studio 2.1.10 自定义提供商的 OpenAI 端点 | `https://certaedge.com` |
| Claude Code 的 `ANTHROPIC_BASE_URL` | `https://certaedge.com` |
| 手写 Chat Completions HTTP 请求 | `https://certaedge.com/v1/chat/completions` |
| 手写 Responses HTTP 请求 | `https://certaedge.com/v1/responses` |

客户端可能自动追加 `/v1` 或端点名称。若响应是 HTML，或路径出现 `/v1/v1`，请检查是否重复或遗漏路径。

## 选择模型

1. 打开<PlatformLink to="models">模型目录</PlatformLink>。
2. 确认模型支持所需协议和能力，例如工具调用、视觉或流式输出。
3. 复制完整模型 ID，保持大小写、连字符和版本后缀一致。
4. 确认 API Key 所属分组和模型限制允许访问该模型。

模型显示名称和 API 模型 ID 可能不同。复制页面提供的 ID，不使用自己起的聊天窗口名称；先选择支持目标协议的模型，再在客户端中启用同一种协议。

若模型目录没有显示可用协议，先联系平台支持确认。模型列表接口返回某个 ID，只能证明它可被列出，不保证它支持所有端点。
