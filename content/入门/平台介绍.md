# 平台介绍

CertaEdge 为应用和开发工具提供统一的模型 API 入口。创建 API Key 后，选择账号可用的模型，即可按对应协议发送请求。

## 接入三要素

| 配置项 | CertaEdge 的填写方式 |
| --- | --- |
| Base URL | OpenAI 兼容接口填写 `https://certaedge.com/v1` |
| API Key | 在<PlatformLink to="keys">控制台</PlatformLink>创建的模型调用密钥 |
| Model | 从<PlatformLink to="models">模型目录</PlatformLink>复制完整模型 ID |

工具对路径的处理不同。Claude Code 使用 `https://certaedge.com`，由客户端追加 `/v1/messages`；使用 OpenAI 兼容 SDK 时通常填写带 `/v1` 的地址。

## 从第一次调用开始

1. [注册账号并准备可用余额](/getting-started/account)。
2. [创建 API Key](/getting-started/api-key)，按应用设置额度和权限。
3. [确认接口地址与模型](/getting-started/base-url)。
4. [发送一次简短的测试请求](/getting-started/first-request)。
5. 在[工具教程](/tools/)中找到常用客户端，按步骤配置。

## 选择匹配的协议

CertaEdge 提供多种兼容接口。模型名称、端点与参数必须匹配；一个工具支持自定义 Base URL，并不表示它支持全部模型能力。

| 使用方式 | 常见端点 |
| --- | --- |
| OpenAI Chat Completions | `/v1/chat/completions` |
| OpenAI Responses | `/v1/responses` |
| Anthropic Messages | `/v1/messages` |
| Gemini 原生调用 | `/v1beta/models/{model}:generateContent` |

以当前模型目录和客户端支持情况为准。

## 密钥与用量

- 为不同应用分别创建 API Key，方便查看用量、限制权限和单独停用。
- 不要把真实密钥提交到代码仓库或放进公开截图。
- 调用后打开<PlatformLink to="logs">使用日志</PlatformLink>，核对模型、状态和费用。
- CertaEdge API Key 和第三方客户端的订阅是不同服务。客户端自己的付费功能是否可用，以该产品的规则为准。

遇到错误时，先阅读[常见问题与错误排查](/getting-started/troubleshooting)。

需要使用已经开放的视频、音乐或绘图服务时，从[生成任务 API](/generation/)选择对应接口。它们通常采用提交后查询的流程，不直接套用普通聊天请求体。
