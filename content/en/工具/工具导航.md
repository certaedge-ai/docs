# Choose Your Tool {#选择你的工具}

Complete your [first request](/en/getting-started/first-request) or an [HTTP test](/en/tools/custom-app) to verify the key and model before configuring a client. If you are unfamiliar with the command line, start with [Cherry Studio](/en/tools/cherry-studio).

<ToolGrid />

## Choose by workflow {#按使用方式选择}

| Goal | Recommended guide |
| --- | --- |
| Connect a chat client first | [Cherry Studio](/en/tools/cherry-studio) |
| Work on a project with a coding assistant | [Codex](/en/tools/codex), [Claude Code](/en/tools/claude-code), [DeepSeek Harness](/en/tools/deepseek-harness) |
| Submit generation tasks, wait, and download automatically | [n8n generation workflow](/en/tools/n8n#生成任务工作流) |
| Refine a prompt with an LLM, then submit a media task | [Dify workflow](/en/tools/dify#用工作流调用生成任务) |
| Query tasks and save results directly in an application | [Python polling](/en/tools/custom-app#用-python-查询生成任务) |
| Integrate using API parameters | [Generation APIs](/en/generation/) |

Video, music, and other task models may not work when entered directly in a chat client's model field. Check whether the client can make the required HTTP requests, retain the task ID, and retrieve results. If it cannot, use an HTTP workflow or application script.

## General setup flow {#通用配置流程}

1. Create an API Key in the <PlatformLink to="keys">console</PlatformLink>.
2. Copy an available model ID from the <PlatformLink to="models">model catalog</PlatformLink>.
3. Choose the provider type required by your tool, then enter the Base URL and API Key.
4. Send a short message, confirm you receive a result, and check the console's usage records.

## Which address should you enter? {#地址怎么填写}

| Connection method | Example address | Notes |
| --- | --- | --- |
| OpenAI-compatible SDK | `https://certaedge.com/v1` | SDKs usually append `chat/completions` or `responses` |
| Claude Code | `https://certaedge.com` | Anthropic clients usually append `/v1/messages` |
| Cherry Studio 2.1.10 custom provider's OpenAI endpoint | `https://certaedge.com` | Preview must end in `/v1/chat/completions`; select a model and use Verify and enable |
| Custom HTTP request | `https://certaedge.com/v1/chat/completions` | Enter the complete endpoint and do not append the same path again |

Tools differ in how they handle trailing slashes, version paths, and endpoint suffixes. Follow the guide for your tool and installed version.

## Check before use {#使用前确认}

- Model IDs, available groups, permissions, and prices depend on your account's current model catalog and console.
- Configuration diagrams explain the fields; they do not mean every client version has been tested.
- For a first connection, set a controlled quota and make one short request before connecting automated workflows.
