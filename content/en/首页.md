## Have these three things ready {#接入前-准备这三项}

| Setting | Where to find it |
| --- | --- |
| **Base URL** | The general OpenAI-compatible API uses `https://certaedge.com/v1`. See each tool's guide for its exact URL format. |
| **API key** | Create one in the <PlatformLink to="keys">console</PlatformLink>. Keep the full key out of public posts. |
| **Model ID** | Copy the full ID from the <PlatformLink to="models">model catalog</PlatformLink>. Availability depends on your account. |

New here? Start with [Account and balance](/en/getting-started/account). If you already have an account, [create an API key](/en/getting-started/api-key). To try your first conversation without writing code, follow the [Cherry Studio guide](/en/tools/cherry-studio).
