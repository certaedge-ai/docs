# Generation Tasks API Overview {#生成任务-api-接入总览}

Generation tasks produce video, music, or images that take time to complete. Call the API directly or combine its endpoints in tools such as n8n and Dify.

## Check access before you start {#先确认可以调用}

Prepare a valid <PlatformLink to="keys">API Key</PlatformLink>, sufficient balance, and a target model enabled for your account. An endpoint's existence does not mean every model is available. Check the <PlatformLink to="models">model catalog</PlatformLink> or the model's instructions for its protocol, required parameters, and billing method.

| What you need | Guide | Task identifier |
| --- | --- | --- |
| OpenAI-compatible video generation | [Video Generation and Downloads](/en/generation/video) | `id` in the submission response |
| Music and lyrics | [Music and Lyrics](/en/generation/music) | `data` in the native submission response |
| Midjourney images and follow-up actions | [Midjourney Images](/en/generation/midjourney) | `result` in the submission response |
| Unified task queries and multiple artifacts | [Generic Tasks and Artifacts](/en/generation/tasks) | `task_id` |
| Background submission in Responses format | [Background Responses](/en/generation/responses) | `resp_...`; also keep `metadata.task_id` |

Identifiers and status fields differ between endpoints. Save the actual submission response; do not invent task identifiers from the examples.

## Authentication and URLs {#鉴权与地址}

Full URLs in this chapter combine `https://certaedge.com` with the relevant endpoint path. Include this header in REST requests:

```http
Authorization: Bearer sk-YOUR_API_KEY
```

For JSON submissions, also set `Content-Type: application/json`. Replace the placeholder with your complete API Key and keep one space after `Bearer`.

The Bash examples work on macOS, Linux, or WSL. First set the key in your current terminal:

```bash
export CERTAEDGE_API_KEY='sk-YOUR_API_KEY'
```

On Windows PowerShell, use `curl.exe` as described in the [custom application guide](/en/tools/custom-app), or use that page's Python polling example. Do not paste Bash backslash line continuations directly into PowerShell.

## Complete a task {#一次任务怎么完成}

1. Submit once, check both HTTP and application-level status, and save the public task ID.
2. Query the original task at intervals without resubmitting it.
3. On success, read the result or artifact list. On failure, read the error details.
4. Save files you need to keep and check <PlatformLink to="tasks">task logs</PlatformLink> and usage.

Use a valid API Key from the same account for submission, polling, and downloads. Generation, resubmission, and follow-up variations may each incur charges. See [Status, Polling, and Billing](/en/generation/lifecycle) for waiting and failure handling.

## Learn through your tools {#按工具学习}

- [n8n](/en/tools/n8n#生成任务工作流): combine HTTP Request, Wait, and conditional branches.
- [Dify](/en/tools/dify#用工作流调用生成任务): use an LLM to prepare a prompt, then submit it through an HTTP node.
- [Custom applications](/en/tools/custom-app#用-python-查询生成任务): retrieve results with a polling script that has a limit.

Ordinary chat clients and coding assistants may not handle media tasks directly. Entering a video model ID in a chat model field does not complete the integration.
