# 选择你的工具

先完成[首次调用](/getting-started/first-request)或[HTTP 测试](/tools/custom-app)，确认密钥和模型可用，再配置客户端。没有命令行使用经验时，可以先从 [Cherry Studio](/tools/cherry-studio)开始。

## 按使用方式选择

| 需求 | 推荐阅读 |
| --- | --- |
| 先接入一个聊天客户端 | [Cherry Studio](/tools/cherry-studio) |
| 用代码助手操作项目 | [Codex](/tools/codex)、[Claude Code](/tools/claude-code)、[DeepSeek Harness](/tools/deepseek-harness) |
| 自动提交生成任务并等待下载 | [n8n 生成任务流程](/tools/n8n#生成任务工作流) |
| 用模型整理提示词，再提交媒体任务 | [Dify 工作流](/tools/dify#用工作流调用生成任务) |
| 直接在应用里查询任务和保存结果 | [Python 轮询](/tools/custom-app#用-python-查询生成任务) |
| 按接口参数接入 | [生成任务 API](/generation/) |

视频、音乐等任务模型不一定能填进聊天客户端的模型栏直接使用。先确认客户端能否发起对应 HTTP 请求、保留任务 ID 并读取结果；不能时，改用 HTTP 工作流或应用脚本。

## 通用配置流程

1. 在<PlatformLink to="keys">控制台</PlatformLink>创建 API Key。
2. 在<PlatformLink to="models">模型目录</PlatformLink>复制实际可用的模型 ID。
3. 按工具要求选择服务商类型，填写 Base URL 和 API Key。
4. 发送一条简短消息，确认能够收到结果，再检查控制台使用记录。

## 地址怎么填写？

| 使用方式 | 地址示例 | 注意事项 |
| --- | --- | --- |
| OpenAI 兼容 SDK | `https://certaedge.com/v1` | SDK 通常继续拼接 `chat/completions` 或 `responses` |
| Claude Code | `https://certaedge.com` | Anthropic 客户端通常自行拼接 `/v1/messages` |
| Cherry Studio 2.1.10 自定义提供商的 OpenAI 端点 | `https://certaedge.com` | 请求预览应为 `/v1/chat/completions`；按教程选择模型并“检测并启用” |
| 自定义 HTTP 请求 | `https://certaedge.com/v1/chat/completions` | 需要填写完整端点，不能再次拼接相同路径 |

工具对末尾斜杠、版本路径和端点追加的处理可能不同，以工具教程和当前版本为准。

## 使用前确认

- 模型 ID、可用分组、权限与价格以当前账号的模型目录和控制台为准。
- 图中的配置示意用于解释字段，不表示已经在所有客户端版本完成实测。
- 初次接入先设置可控额度，完成一次简短调用，再接入自动化流程。
