# 生成任务 API 接入总览

生成任务用于需要等待结果的视频、音乐或绘图。你可以直接调用 API，也可以通过 n8n、Dify 等工具组合这些接口。

## 先确认可以调用

准备一把有效的<PlatformLink to="keys">API Key</PlatformLink>、可用余额，以及当前账号已开放的目标模型。接口存在不代表所有模型都能调用；在<PlatformLink to="models">模型目录</PlatformLink>或该模型说明中确认协议、必填参数与计费方式。

| 需求 | 阅读入口 | 任务标识 |
| --- | --- | --- |
| OpenAI 兼容视频生成 | [视频生成与下载](/generation/video) | 提交响应的 `id` |
| 音乐与歌词 | [音乐与歌词](/generation/music) | 原生接口响应的 `data` |
| Midjourney 绘图及后续操作 | [Midjourney 绘图](/generation/midjourney) | 提交响应的 `result` |
| 通用任务查询、多种产物 | [通用任务与产物](/generation/tasks) | `task_id` |
| 使用 Responses 形式后台提交 | [后台 Responses](/generation/responses) | `resp_...`，并保留 `metadata.task_id` |

不同接口的 ID 和状态字段不完全相同。提交后保存真实响应，不根据示例 ID 自己拼造任务。

## 鉴权与地址

本章的完整 URL 使用 `https://certaedge.com` 加对应路径。REST 请求带上：

```http
Authorization: Bearer sk-YOUR_API_KEY
```

JSON 提交再设置 `Content-Type: application/json`。把占位密钥替换成自己的完整密钥，`Bearer` 后保留一个空格。

Bash 示例适用于 macOS、Linux 或 WSL，先在当前终端设置：

```bash
export CERTAEDGE_API_KEY='sk-YOUR_API_KEY'
```

使用 Windows PowerShell 时，可按[自定义应用教程](/tools/custom-app)使用 `curl.exe`，或使用该页的 Python 任务轮询示例。不要把 Bash 的反斜杠换行直接粘进 PowerShell。

## 一次任务怎么完成

1. 提交一次请求，检查 HTTP 与业务状态，保存公开任务 ID。
2. 间隔查询原任务，不重复提交。
3. 成功后读取结果或产物列表；失败时读取错误原因。
4. 保存需要长期使用的文件，并核对<PlatformLink to="tasks">任务日志</PlatformLink>及用量。

提交、轮询和下载使用同一账号的有效密钥。生成、重提和后续变体可能分别产生费用；等待和失败处理详见[状态、轮询与费用](/generation/lifecycle)。

## 按工具学习

- [n8n](/tools/n8n#生成任务工作流)：HTTP Request、Wait 和条件分支组合。
- [Dify](/tools/dify#用工作流调用生成任务)：LLM 整理提示词，再由 HTTP 节点提交。
- [自定义应用](/tools/custom-app#用-python-查询生成任务)：用有上限的轮询脚本获取结果。

普通聊天客户端和代码助手不一定能直接处理媒体任务。不要只把视频模型 ID 填入聊天模型栏就认为已经接入。
