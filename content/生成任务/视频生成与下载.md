# 视频生成与下载

本页适用于已经开放 **OpenAI 兼容视频协议**的模型。先完成[密钥与鉴权准备](/generation/)，再确认模型支持的时长、尺寸和输入格式。

## 1. 保存生成请求

下面是支持 `seconds` 和 `size` 的 Sora 类文本转视频示例。创建 UTF-8 文件 `video.json`，替换真实模型 ID；其他视频模型按各自说明调整参数，不只替换模型名称。

```json
{
  "model": "YOUR_VIDEO_MODEL_ID",
  "prompt": "固定镜头，一只猫在阳光下伸懒腰，画面自然平稳。",
  "seconds": "4",
  "size": "1280x720"
}
```

| 字段 | 说明 |
| --- | --- |
| `model` | 账号可用且支持此协议的完整模型 ID |
| `prompt` | 描述画面、主体、动作与镜头 |
| `seconds` | 此示例为 4 秒；必须使用目标模型支持的值 |
| `size` | 此示例为横屏 1280×720；尺寸也受模型限制 |

## 2. 提交一次任务

在文件所在目录、已设置密钥的终端执行：

```bash
curl -sS -X POST https://certaedge.com/v1/videos \
  -H "Authorization: Bearer $CERTAEDGE_API_KEY" \
  -H 'Content-Type: application/json' \
  --data-binary @video.json
```

成功响应通常包含以下字段，值仅示意：

```json
{
  "id": "task_EXAMPLE",
  "object": "video",
  "status": "queued",
  "model": "YOUR_VIDEO_MODEL_ID",
  "progress": 0
}
```

保存真实 `id`。HTTP 200 和 `queued` 只表示任务已接收，不表示视频已经生成。

需要参考图片的模型可能要求 multipart 文件或额外参数。只在该模型明确支持时使用对应字段；不要给所有视频模型套用同一张图或同一种上传格式。

## 3. 查询状态

把 `task_EXAMPLE` 换成刚才的真实 ID：

```bash
export CERTAEDGE_TASK_ID='task_EXAMPLE'
curl -sS "https://certaedge.com/v1/videos/$CERTAEDGE_TASK_ID" \
  -H "Authorization: Bearer $CERTAEDGE_API_KEY"
```

- `queued`、`in_progress`：继续等待，建议约 15 秒后再查询。
- `completed`：进入下载步骤。
- `failed`：查看 `error` 等错误内容，不重复查询等待成功。

同一 ID 可以重复查询；不要在每次查询前重新执行提交命令。

## 4. 下载结果

仅在状态为 `completed` 后执行。建议在独立测试目录下载，若已有 `result.mp4`，先将旧文件改名保存：

```bash
curl --fail -L "https://certaedge.com/v1/videos/$CERTAEDGE_TASK_ID/content" \
  -H "Authorization: Bearer $CERTAEDGE_API_KEY" \
  --output result.mp4
```

查询响应不一定直接包含上游视频 URL，使用上述内容接口。下载后检查文件能否正常播放；未完成时返回的 JSON 不是视频文件。

## 在工具里组合

[n8n](/tools/n8n#生成任务工作流)可以定时查询并在成功时下载；[Dify](/tools/dify#用工作流调用生成任务)适合先组织提示词再提交；[Python 示例](/tools/custom-app#用-python-查询生成任务)适合应用内轮询。

400 通常需要核对模型参数；401 核对密钥；未开通模型或协议时按错误正文处理。完整说明见[轮询与费用](/generation/lifecycle)。
