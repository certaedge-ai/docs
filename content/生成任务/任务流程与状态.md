# 状态、轮询与费用

部分生成任务不会在一次请求中立即返回最终结果。提交成功只表示任务已被接收，需要继续查询直到成功或失败。

## 哪些场景适用

异步任务用于平台已经开放、且当前账号有权限调用的视频、音乐等生成接口。先在<PlatformLink to="models">模型目录</PlatformLink>或平台提供的对应接口说明中确认是否已开放，再进行接入；不能仅凭模型名称推断支持异步任务。

普通 Chat Completions 对话和逐字返回的流式输出，不属于本页的“提交后按任务 ID 查询”流程。只使用聊天客户端或代码助手时，可以跳过本页；不要为普通聊天请求随意添加异步参数。

## 标准流程

```text
提交任务 → 保存返回的任务 ID → 间隔查询状态 → 读取最终结果或错误原因
```

具体提交路径、查询路径、任务 ID 字段和结果字段取决于接口。接入前取得该模型对应的接口说明；本页解释任务处理流程，不提供某一种视频或音乐接口的完整请求体，不要猜测路径直接提交。

不同接口使用不同的任务 ID 和状态字段，先选择匹配的一组：

| 接口 | 提交后保留 | 查询时检查 | 成功 / 失败 |
| --- | --- | --- | --- |
| 视频 | `id` | `status` | `completed` / `failed` |
| 通用任务 | `task_id` | `status` | `SUCCESS` / `FAILURE` |
| SunoAPI 原生 | `data` | `data.status` | `SUCCESS` / `FAILURE` |
| Responses 后台 | `id`，同时保留 `metadata.task_id` | `status` | `completed` / `failed`、`incomplete` |
| Midjourney | `result` | `status` | `SUCCESS` / `FAILURE` |

具体请求示例见[视频](/generation/video)、[音乐与歌词](/generation/music)、[Midjourney](/generation/midjourney)、[通用任务](/generation/tasks)和[后台 Responses](/generation/responses)。

OpenAI 兼容视频接口的常见路径如下：

| 操作 | 方法与路径 |
| --- | --- |
| 提交视频生成任务 | `POST /v1/videos` |
| 查询任务状态 | `GET /v1/videos/{任务ID}` |
| 读取成功任务的内容 | `GET /v1/videos/{任务ID}/content` |

这些是完整端点路径，相对于服务根地址 `https://certaedge.com` 使用。查询时使用提交响应中的公开任务 ID，并用同一账号的有效 API Key 鉴权；不要改用上游服务内部 ID。音乐或厂商原生接口有自己的路径，不能直接套用视频接口。

## 在控制台查看任务

已通过工具或 API 提交任务后，可打开<PlatformLink to="tasks">任务日志</PlatformLink>，按时间查找任务，核对任务 ID、状态和结果。找不到记录时，先确认是否使用当前账号的密钥，并保留客户端返回的任务 ID 向支持反馈。

## 处理状态

| 状态类型 | 处理方式 |
| --- | --- |
| 等待或处理中 | 保留任务 ID，等待下一次查询 |
| 成功 | 读取接口返回的结果或文件地址 |
| 失败 | 记录错误内容，核对参数和素材后再决定是否重新提交 |

OpenAI 兼容视频查询中的状态通常为 `queued`、`in_progress`、`completed`、`failed`，分别对应排队、处理中、完成、失败。其他接口或控制台可能使用不同名称，以该接口说明为准。HTTP 200 也不一定表示生成成功，应同时检查响应正文。

## 控制查询频率

- 可从每 15 秒查询一次开始，遇到限流时延长间隔；接口有明确要求时按接口要求执行。任务状态可能按周期更新，连续查询得到相同状态不一定是任务卡住。
- 设置业务侧总等待时间，超时后保留任务 ID，方便继续查询和排错。
- 客户端超时后先检查是否已经拿到任务 ID，不要立即重复提交。
- 重新提交可能生成独立任务并产生额外费用。

## 给轮询设置上限

应用或工作流必须设置最大查询次数或总等待时间。例如每 15 秒查询、最多 60 次，达到上限后保留任务 ID 并结束本次等待。它只是业务等待策略，不代表服务承诺在该时间内完成。

遇到 HTTP 错误或无法识别状态时按错误分支处理，不无限等待，也不把查询失败当成生成失败后立刻重提。

## 结果与费用

及时保存需要长期使用的结果文件。若素材 URL 或结果 URL 有有效期，应在有效期内完成读取。

费用和失败后的账务处理以控制台记录及平台当前规则为准，不根据客户端超时或任务失败状态推断已退款。

## 排查问题

| 问题 | 检查方向 |
| --- | --- |
| 任务不存在 | ID 是否来自本次提交，是否使用同一账号与匹配查询接口 |
| 一直处理中 | 是否仍在排队，查询间隔和业务超时是否合理 |
| 素材无法读取 | URL 能否被服务端访问、文件格式和大小是否符合要求 |
| 返回 429 | 降低并发与查询频率，按错误说明退避重试 |
| 返回失败状态 | 保存完整错误内容和任务 ID，再检查参数与模型能力 |

更多状态码说明见[常见问题与错误排查](/getting-started/troubleshooting)。需要协助时，可通过 <PlatformLink to="support">CertaEdge 在线客服</PlatformLink>提供任务 ID、时间和错误信息，不要发送完整 API Key。
