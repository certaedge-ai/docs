## 接入前，准备这三项

| 配置项 | 从哪里获取 |
| --- | --- |
| **Base URL** | 通用 OpenAI 兼容接口为 `https://certaedge.com/v1`；不同工具的填写方式见各自教程 |
| **API Key** | 在<PlatformLink to="keys">控制台</PlatformLink>创建，避免把完整令牌发到公开场合 |
| **模型名称** | 在<PlatformLink to="models">模型目录</PlatformLink>复制完整 ID，以当前账号实际可用模型为准 |

还没有账号？从[注册与充值](/getting-started/account)开始；已有账号则先[创建 API Key](/getting-started/api-key)。不想编写代码时，可按 [Cherry Studio 教程](/tools/cherry-studio)完成第一次对话。
